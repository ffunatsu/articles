以前も似た記事を書いた気がするし、そうしたことを書くのは最後にしたいとか書いてたけど、少し現状が変化してきたのもあって改めて書きたい。

自分は昔 Cody というコーディングアシスタントを愛用していた時代があったのだけど、安すぎたせいかサービス終了してしまった。その後 GitHub Copilot に移り、定額制が廃止されたので、しばらく何も使っていない期間が空いたのちに、GoogleのAntigravity IDE（および同名のVSCode拡張機能）を試用している。

どのコーディングアシスタントも、楽しいといえば楽しい。話し相手ができるし、力をアシストしてくれる感じがある。

一方で、不思議とものすごく疲れる。たぶん、ペアプログラミングが疲れるのと同じで、一つ一つのコードを理解してレビューしたり、リジェクトしようとすることが、結果的にコードを書いているときの何倍も急かされる感じになって疲れるのだと思う。

で、結論としては、自分は今度もAIアシストは使わないと思う。

GitHub Copilotの時点で、実際あんまり使っていなかったし、その後使わない期間もあったので、そこに戻るだけだと思う。

月額費用もだんだん高騰しているので、そういう意味でもいいかなと思いつつ、毎回丁寧にAPIドキュメントを精査したりなどの大変な作業に戻る形になるので、生産性という意味ではだいぶ下がると思う。

それでも、そうした調査自体が楽しかったりもするし、AIアシストで疲れてコーディングが嫌になるくらいなら、ゆっくり自分のペースでコードを書いていったほうが長期的には楽しそうなように思う。

オープンソース開発での折り合いはなかなか難しいところがあって、元々AI禁止になっていれば問題ないものの、AI推進派のオープンソースプロジェクトに参画してしまったときに、AIのスピード感と膨大なコード量を精査するのが大変だけど、たぶん今後はそもそもそういうプロジェクトには参画しないのではないかと思うし、思いたい。
